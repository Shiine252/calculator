# Orbit Calculator

A simple, responsive calculator built with plain HTML, CSS, and JavaScript. It runs in a web browser and does not need a build step or installation.

## Run the calculator

Open `index.html` in your browser. The calculator works locally; an internet connection is only needed to load the optional Google Fonts.

## Features

- Addition, subtraction, multiplication, and division
- Decimal input, percentage, and sign change
- Delete the last digit or clear the calculation
- Shows the previous calculation above the current value
- Displays `Error` for division by zero
- Keyboard support
- Responsive dark interface

## Keyboard controls

| Key | Action |
| --- | --- |
| `0`–`9` | Enter a digit |
| `.` | Enter a decimal point |
| `+`, `-`, `*`, `/` | Choose an operation |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last digit |
| `Escape` or `C` | Clear |
| `%` | Convert the current value to a percentage |

## Project files

- `index.html` — page structure and calculator buttons
- `style.css` — layout, colors, and responsive styling
- `script.js` — calculator operations and keyboard controls
